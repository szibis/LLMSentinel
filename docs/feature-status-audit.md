Responses grammar support is bounded; images/provider built-ins/arbitrary grammars/stored histories are intentionally rejected (`docs/client-quality-inspection.md:3-16`). Local client streams are buffered; this is not native token streaming.
- **Narrow agent-progress gate:** `internal/localgateway/progress.go:49-125` detects a third identical successful read-only lookup on unchanged evidence and a narrowly matched unfinished final response after tools. It is connected at `claude.go:578-581`, with one recovery at `:404-425`. It is not a general semantic correctness scorer.
- **Learning capture:** `gateway.go:162-164`, `internal/localgateway/training_ingest.go`, `training.go:76-246` implement opt-in private bounded JSONL records and rotation/redaction. `training.go:162-170` forces unscored/default quality and `training_eligible=false`. Commercial hook records are reported/untrusted capture, not independently authenticated provider/quality evidence. This is data collection, not model training.
- **Native prompt-cache integration:** Sentinel sends stable hashed session/profile scope (`internal/localgateway/claude.go:84-109`, `:438`; `gateway.go:320`). External MLX-Flash performs exact token-prefix snapshot reuse, not Sentinel semantic answer caching. `docs/gemma-lfm-lab.md:31-56` explicitly distinguishes these paths and says cache reuse does not shrink logical context or prove billing savings. Current repo contains integration and telemetry, not an in-process KV cache engine.
- **Lab supervisor, controls, native tools, live runtime dashboard/status:** concrete Go implementations in `internal/lab`, `internal/clientcontrol`, `internal/labdashboard`, `internal/labstatus`, `cmd/sentinel-tools`. These are the modern path; do not infer legacy dashboard correctness from this modern UI.
